# 成交额同比因子：全A 与当前指数（看涨/看跌）

**Status:** done（2026-11-09）
**Source:** 用户当面需求（「作为权威专业的股指分析师…」）
**分支:** `feat/volume-ratio-factors`

## 需求

根据「全A 前一日累计成交额对比」与「当前指数前一日累计成交额对比」，加入看涨看跌因子。

## 已确认事实

- 现有 `market_turnover` 已有一个「市场总成交额」因子（±10/±3）：上证+深证成指**按交易进度
  折算全天** vs 前一交易日全天，再按上证涨跌做量价配合。与本次需求高度重叠。
- 数据源：腾讯 `day/query` 给最近 5 个交易日的**分钟级累计成交额**（242 点/日，09:30–15:00），
  上证 `1.000001` 与深证 `0.399001` 都有；深证成指与深证综指在该源返回同一数值（都是深市总额），
  所以「上证 + 深证成指 = 全A」成立（不含北交所）。
- 关联指数在 `universe.TRACK_INDEX`（上证50/沪深300/中证500/科创50/创业板指/深证100）。

## 已拍板的决策

1. **替换旧口径**：全A 同时间点对比取代「折算全天」，沿用 ±10 的位置；不做两套并存。
2. **「当前指数」= 当前 ETF 的关联指数**（9 只各算各的），不是固定上证。
3. **直接同比**（指数今日累计 ÷ 昨日同时点），不做扣全A的超额同比。
4. **权重**：全A ±10、指数 ±8；阈值 **1.10 / 0.90**；平量 0。
5. **缩量按背离口径反向**（缩量上涨记负、缩量下跌记正），且**给满权**。
6. `|涨跌| ≤0.1%` 不做量价配合；09:45 前不计分；收盘后按全天同比。

## 实现

- `services/volume_ratio.py`（新）：纯函数 `cum_at` / `compare_at` / `score` / `merge` /
  `pick_days` / `evaluate` / `looks_stale`；取数 `all_a()`（±10）与 `index_ratio(secid, pct, label=)`（±8），
  30s 缓存，`_series()` 在疑似旧缓存时用 `bust` 重取一次。
- `services/em.py`：新增 `day_series()`（分钟级累计成交额）与纯解析 `parse_day_series()`；
  `day_amounts()` 改为复用它（顺带修掉「取最后 N 条其实是最旧 N 天」的隐患）。
- `services/market_turnover.py`：改成 `volume_ratio.all_a()` 的薄壳，保留 `snapshot()` / `factor_text()`，
  调用方零改动。
- `services/strategy.py`：`bias_score(..., index_volume=)` 新增「指数量能」明细（为 0 不写）；
  `_compute_dirs()` / `analyze()` 按 `TRACK_INDEX` 取关联指数同比，bundle 多一个 `index_volume`。

## 验证

- `pytest -q`：**762 passed**（新增 `tests/test_volume_ratio.py`：取点对齐、比率、放量顺势/缩量背离
  的四个符号、1.10/0.90 边界、平量、横盘、开盘初期、缺数据、多市场合并、盘中/收盘后/周末取日、
  `parse_day_series` 的升序、以及 `market_turnover.factor_text` 行为）。
- 线上（2026-11-09 收盘后，全A 1.48 万亿 vs 11-06 的 1.66 万亿）：
  - 全A 缩量 0.89x → 明细「市场总成交额 −10」，信号文案
    「全A 全天成交 1.48 万亿，较前一交易日缩量 0.89x（基准 1.66 万亿），上证 +0.32%」。
  - 588000 科创50（涨 +0.30%、指数缩量 0.80x）→ 背离 → 明细「指数量能 −8」，bundle `index_volume`
    文案「科创50 全天成交 0.07 万亿，较前一交易日缩量 0.80x」。
  - 510500 中证500（跌 −0.17%、缩量）→ 背离反向 →「指数量能 +8」；159915 创业板指 0.91x 平量 → 不写入。
  - 510300 沪深300 pct 0.05%（横盘）→ 指数量能 0，符合「横盘不给方向」口径。
- 未验证：真实盘中的同时间点对齐（验证时已收盘，只有单测覆盖 10:30 的对齐路径）。
